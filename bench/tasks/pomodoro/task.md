Build a Pomodoro timer web app in the current folder as three files: index.html, style.css and app.js.
No frameworks, no build step, no external resources.
Requirements:
- Show the remaining time as mm:ss.
- Work sessions of 25 minutes and breaks of 5 minutes by default; both durations are editable with number inputs.
- Start, Pause and Reset buttons. When a work session ends, switch to a break, and back.
- Count completed work sessions and keep that count in localStorage so it survives a reload.
index.html must link style.css and load app.js. Stop when the app is complete.
